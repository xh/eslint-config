# Hoist eslint-config

A shareable [ESLint](https://eslint.org/) flat config with XH's coding conventions and best
practices for Hoist React based development.

This is published as its own dedicated package so that all Hoist apps can share a single, tested
lint config and toolchain. ESLint and all required plugins are direct dependencies of this
package, so apps need only depend on `@xh/eslint-config` and extend it from their own
`eslint.config.js`. See <https://eslint.org/docs/latest/extend/shareable-configs>.
